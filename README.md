# jamesdeen.github.io
This is my certification training exams for Salesforce Certified Platform Data Architect and Salesforce Certified Platform Sharing and Visibility Architect.

## Project structure

- `index.html` is the certification landing page.
- `data-architect-home.html` lists the six Data Architect parts.
- `data-architect-part.html` displays a selected part's quiz.
- `platform-developer-home.html` lists the three Platform Developer 1 parts.
- `platform-developer-part.html` displays a selected Platform Developer 1 part's quiz.
- `css/` contains the shared and page-specific stylesheets.
- `js/` contains the shared quiz logic (`data-architect-quiz.js`) and the question banks.
